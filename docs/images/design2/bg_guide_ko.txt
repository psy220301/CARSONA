카르소나 배경 사용 가이드 (디자인 2)

1. 기본
   bg_default.png(홈·첫 만남), bg_reveal.png(성장 공개). 둘 다 1700×1200px, 투명 없음.
   좌표 기준은 배경 원본 1700×1200, 원점 좌상단, X 오른쪽 · Y 아래로 증가.
   두 배경은 언덕 · 지평선 위치가 같아 화면이 바뀌어도 아바타 위치를 그대로 두면 된다.

2. 아바타 위치 (권장)
   backgrounds.json의 avatar_anchor 사용.
   아바타 1024×1024 캔버스를 1.1배(1126×1126)로 (287, 41)에 그리면
   발(캔버스 y=999)이 배경 y=1140, 가로 중앙 x=850에 온다. 세 단계 모두 같은 사각형.
   아이템은 디자인 1의 placements.json 좌표에 같은 배율(1.1)과 같은 시작점(287, 41)을 적용.
     아이템 사각형 = (287 + x*1.1, 41 + y*1.1, width*1.1, height*1.1)
   바닥 그림자는 배경에 없음.

3. 화면 크기가 다를 때
   배경은 가운데 기준으로 꽉 채운다(centerCrop).
   scale = max(viewWidth / 1700, viewHeight / 1200)
   offsetX = (viewWidth - 1700 * scale) / 2
   offsetY = (viewHeight - 1200 * scale) / 2
   배경 위의 모든 좌표(아바타 사각형 포함)는 화면 좌표 = (offset + 좌표 * scale).
   가로·세로 배율을 따로 쓰지 않는다.

4. 참고 좌표
   bg_reveal 빛 중심 (850, 700), 링 반지름 440. 성인 아바타 몸통 위쪽이 빛 중심에 온다.
   bg_default 달 중심 (1420, 210). 오른쪽 위 UI를 올리면 달이 가려질 수 있음.
   위쪽 0~200px은 별만 있어 이름표·버튼 자리로 써도 된다.
